## Recommended Features to Add

### 1. ATS Keyword Matching (High Priority)
- User pastes job description alongside resume
- AI extracts keywords from JD, scores resume against them
- Shows "keyword gap" — terms in JD missing from resume
- Generates optimized resume with keywords injected

### 2. Bullet Point Rewriter (High Priority)
- Identify weak action verbs ("Worked on", "Was responsible for")
- Rewrite bullets with strong verbs + metrics
- Default recommendation integrated into roast output

### 3. Before/After Score (Medium)
- Show score comparison: original vs optimized
- Visual score improvement gauge

### 4. Cover Letter Generator (Medium)
- Generate tailored cover letter from resume + JD
- Pro/Power feature

### 5. Resume Editor (Low)
- In-browser editing of optimized resume
- Power plan feature

### 6. Skill Roadmap (Low)
- Generate learning plan for missing skills
- Pro+ feature
